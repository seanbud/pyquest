# Contributing

Thanks for helping make coding practice clearer, kinder, and more rewarding.

1. Open an issue before a large product or architecture change.
2. Keep course metadata in `course.json`; do not copy third-party course content
   into this repository unless its license permits redistribution.
3. Preserve keyboard access, readable contrast, reduced-motion behavior, and
   the sound toggle when changing the interface.
4. Validate both runtimes: `python server.py` for native mode and
   `?runtime=browser` for browser mode.
5. Never expose the native runner publicly.

Small, focused pull requests are easiest to review. Include the learner-facing
outcome and the checks you ran.
